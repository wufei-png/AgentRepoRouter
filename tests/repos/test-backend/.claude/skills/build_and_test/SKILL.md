# Build and Test Skill

This skill handles building and testing tasks for backend projects.

## When to Use

- Running test suites
- Building project
- CI/CD operations
- Deployment tasks

## Commands

```bash
# Run tests
npm test

# Build project
npm run build

# Run specific test file
npx jest <file>
```
